# E-commerce PHP

E-commerce desenvolvido utilizando PHP puro, MySQL, HTML, CSS e JavaScript.

O projeto foi desenvolvido como uma das minhas primeiras experiências com programação e teve como objetivo aplicar conceitos de desenvolvimento web, integração com banco de dados e criação de uma área administrativa.

## Funcionalidades

- Listagem de produtos
- Visualização de detalhes dos produtos
- Área administrativa
- Login de administrador
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Gerenciamento de banners
- Integração com MySQL

## Tecnologias

- PHP
- MySQL
- MySQLi
- HTML
- CSS
- JavaScript
- XAMPP
